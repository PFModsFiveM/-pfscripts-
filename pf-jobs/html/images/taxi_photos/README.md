# Taxi Vehicle Photos

This directory stores vehicle photos captured using the /vehiclephoto command.

Photos are saved with the format: `vehicle_photo_<model>_<plate>_<timestamp>.jpg`

Example: `vehicle_photo_Taxi_TAXI001_20260306_153045.jpg`

## How to Use

1. `/vehiclephoto` - Enter photo mode with a nearby vehicle
2. `F9` - Capture the vehicle photo
3. `ESC` - Exit photo mode

Photos are stored here for display in the vehicle rental tablet app.
