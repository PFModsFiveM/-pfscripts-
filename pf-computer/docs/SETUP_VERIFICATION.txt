Error: Announcement doesn't appear as email

Error: Sync events not triggering
→ Check pf-government callbacks.lua modifications
→ Verify TriggerEvent calls are present

Error: Multiple emails for one announcement
→ Normal on first sync while indexes build
→ Future announcements will sync correctly

Error: Old script failing
→ Delete old pf-computer announcement handler if it exists
→ The new sync system replaces it entirely
